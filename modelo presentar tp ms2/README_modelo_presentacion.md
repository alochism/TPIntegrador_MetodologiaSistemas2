# Modelo orientativo de presentación - TPI MS II

Este material es solamente una **guía de ejemplo** para mostrar a los estudiantes una posible forma de presentar el Trabajo Práctico Integrador de Metodología de Sistemas II.

## Contenido del ZIP
- `Modelo_Presentacion_TPI_MSII.pptx`: presentación editable.
- `Guia_rapida_presentacion_TPI_MSII.docx`: explicación breve de cómo usar/adaptar el modelo.
- `README_modelo_presentacion.md`: este archivo.

## Sugerencia para los estudiantes
La presentación puede mantenerse en PowerPoint o exportarse a PDF para incluirla en la carpeta digital del trabajo.

## Estructura sugerida
1. Portada
2. Resumen ejecutivo
3. Presentación del caso
4. Calidad externa vs. interna
5. Deuda técnica y mantenibilidad
6. Code smells detectados
7. SOLID y Clean Code aplicados
8. Refactoring seguro
9. Pruebas y code review
10. Conclusiones

## Recomendaciones
- Reemplazar el caso de ejemplo por el caso real del equipo.
- Incluir capturas, tablas o fragmentos de código solo cuando aporten valor.
- No sobrecargar de texto las diapositivas.
- Mantener coherencia entre el diagnóstico inicial y las mejoras propuestas.
